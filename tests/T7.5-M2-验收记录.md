离线整局驱动 `tests/offline-playthrough.mjs`（Node 内置 WebSocket + CDP，零依赖，不截图）：
启动无头 Chrome（DNS 黑洞 `--host-resolver-rules=MAP * ~NOTFOUND`）→ `file://` 打开 `dist/inkline.html?seed=11`
→ `__CLIENT_DEBUG__.pause(true)` + `restart()` → 页内 bot 复用 `tests/sim-match.mjs` 同一套判定
（经 `__CLIENT_DEBUG__.kernel` 取 CONFIG/ANCHORS/EXIT/groundHeightAt/losBlocker/HITBOX）
→ 每 tick 走客户端真实路径 `aimAt/shoot/erase/botInput` + `runtime.tickOnce()` + `pump()`（事件+渲染+HUD）
→ 直到 `phase==='won'`，并断言 0 外部请求 / 0 控制台错误。
Chrome 路径可用 `CHROME_PATH` 指定，种子可用 `SEED` 覆盖（客户端默认时间种子，故必须显式固定）。
