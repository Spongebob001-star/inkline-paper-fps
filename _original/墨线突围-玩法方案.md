# INKLINE：墨线突围

> 原创浏览器 FPS 玩法方案与首版 Demo 规格
>
> 版本：Prototype 0.1.1｜日期：2026-11-13

## 1. 一句话定位

一款 3–5 分钟一局的纸笔世界 FPS：玩家不是只靠枪清空战场，而是用**画线改地形、擦除破防御、折纸造捷径**，启动三处装订锚点后撤离。

## 2. 借鉴什么，明确不复制什么

### 保留的体验特征

- 纸张、石墨、批注构成的手绘视觉语言。
- 浏览器即开即玩，无账号、无安装、无复杂前厅。
- 第一人称射击的即时反馈与短局紧张感。
- 低多边形场景与程序化材质，控制资源规模。

### 原创边界

- 不使用 PAPERSTRIKE 的名称、品牌、界面排版、文案、代码、音频与模型。
- 不复制其四把武器、武器数值、死亡竞赛击杀目标、三张地图布局、敌人概率命中公式和联机协议。
- 核心目标改为“启动锚点并撤离”，击杀只是争取空间的手段。
- 核心资源改为“墨量”，玩家必须在造墙与擦除之间做选择。

## 3. 设计支柱

1. **枪解决目标，笔改变问题。** 单纯射击可以赢，但合理利用画墙与擦除明显更有效。
2. **每种能力都有战术分工。** 画墙阻断视线与走位；擦除剥离护甲并打断攻击；射击清理已暴露目标。
3. **一眼读懂纸面状态。** 青绿属于玩家与可用交互，校订红属于敌人与危险，石墨黑属于实体环境。
4. **一局讲完整一件事。** 进入纸页 → 启动三个锚点 → 撤离或失败 → 一键重开。

## 4. 世界观与名称

玩家是被夹进工作手册的“修订员”。失控的涂改灵正在覆盖纸页，三处装订锚点维持着纸张的结构。玩家需要重新锚定纸页，然后从页面下方的裁切线撤离。

- 玩家工具：**线规笔**。既能发射墨点，也能把线条实体化。
- 普通敌人：**涂改灵**。由废稿与红色批注皱折而成，体外包裹修正液护甲。
- 场景：**未交付的工作页**。方格纸、折角、装订环、裁切标记共同构成空间。

## 5. 核心循环

```text
观察锚点与敌人位置
        ↓
画线遮挡火力 / 改变追击路线
        ↓
擦除护甲并打断蓄力
        ↓
射击暴露目标，争取交互时间
        ↓
按住 F 启动锚点，触发增援
        ↓
三处锚点完成 → 抵达裁切线撤离
```

资源压力来自同一个墨量槽：造墙越积极，可用于擦除的墨量越少；只用擦除又会失去地形优势。

## 6. 玩家动作与首版数值

| 动作 | 输入 | 规则 |
|---|---|---|
| 移动 / 冲刺 | WASD / Shift | 4.8 / 7.0 m/s |
| 跳跃 | Space | 仅影响纵向闪避与手感，不用于跳过场景围墙 |
| 射击 | 鼠标左键 | 24 伤害，0.14 秒间隔，18 发弹匣 |
| 换弹 | R | 1.25 秒，备弹不限 |
| 画线 | Q 两次 | 第一次确定起点，第二次确定终点；长度 2–6 米 |
| 擦除 | E | 6 米半径，消耗 35 墨量，冷却 3.5 秒 |
| 交互 | 按住 F | 锚点 2 米内持续 1.1 秒；终点交互开启撤离 |
| 暂停 | Esc | 释放鼠标并暂停战斗 |

### 6.1 墨量

- 上限 100，初始 100。
- 连续 0.8 秒未使用画线或擦除后，以 10 点/秒恢复。
- 画线消耗 `20 + 4 × 长度`，即 28–44 点。
- 擦除消耗 35 点。
- 墨量不足时不允许释放，并显示明确反馈。

### 6.2 画线掩体

- 在玩家准星指向的地面确定两个端点，生成垂直于纸面的实体线段。
- 长度 2–6 米，高度 1.65 米，厚度 0.12 米。
- 耐久 120，存在 18 秒，同屏最多 3 面；超出时移除最早的一面。
- 阻挡玩家、敌人和双方射线。
- 敌人被掩体挡住时会转而攻击掩体，避免永久卡死。
- 最后 3 秒逐渐淡化，提示即将失效。

### 6.3 擦除脉冲

- 以玩家为中心扩散，作用半径 6 米。
- 立即移除普通敌人的全部修正液护甲，并打断当前蓄力、眩晕 1 秒。
- 不直接造成生命值伤害，不能替代射击。

## 7. 敌人规则

### 涂改灵（首版唯一敌人）

| 属性 | 数值 |
|---|---:|
| 生命值 | 48 |
| 修正液护甲 | 24 |
| 子弹对护甲效率 | 25%，即每发 6 点 |
| 移动速度 | 2.25 m/s |
| 攻击距离 | 13 米 |
| 蓄力提示 | 0.55 秒红色瞄准线 |
| 命中伤害 | 8 |
| 攻击冷却 | 1.65 秒 |

- 无护甲时，两次命中即可消灭；有护甲且不用擦除时，需要六次命中。
- 敌人先接近玩家，在视线通畅时蓄力攻击；遮挡会打断其对玩家的攻击。
- 被掩体阻挡时攻击掩体；绕开固定场景障碍采用轻量转向，不使用复杂寻路。
- 初始 4 名，每启动一处锚点增援 2 名，同屏上限 7 名。
- 开局提供 4 秒保护期，敌人可以移动，但不会开始蓄力攻击。

## 8. 关卡与胜负

### 单关：未交付的工作页

- 场地约 34 × 34 米，三个锚点呈不对称三角分布。
- 固定掩体由纸块、折角和装订结构组成，不沿用参考站地图。
- 每处锚点周边环境不同：开阔侧面、交叉通道、中央高压区。
- 三处锚点全部启动后，南侧裁切线变为青绿色，玩家抵达并交互即获胜。

### 结算

- 胜利：启动 3 处锚点并完成撤离。
- 失败：生命值降为 0，或 240 秒倒计时结束。
- 结算显示用时、消灭数、画墙数、擦除数，并提供“重新修订”按钮。
- 重开必须完整恢复生命、墨量、弹药、锚点、敌人、掩体与倒计时。

## 9. 后续原创机制：折纸地形

折纸不塞进首版 Demo，避免同时验证过多变量。第二阶段建议只加入一种：

- 对准带虚线的折角按 Q，将纸面翻起为临时坡道或遮挡。
- 同一折角只有两个确定状态，不做任意形变。
- 折起会封闭一条地面通道、打开一条高位捷径，用于改变锚点之间的路线。
- 它改变“路径”，画墙改变“遮挡”，擦除改变“目标状态”，三者职责不重叠。

## 10. 视觉与声音规范

### 色彩 Token

| 名称 | 色值 | 用途 |
|---|---|---|
| Paper | `#F3F1E7` | 冷白纸张底 |
| Graphite | `#20242A` | 文字、实体轮廓、武器 |
| Player Teal | `#007F7B` | 画线、可用交互、完成状态 |
| Correction Red | `#E34B3F` | 敌人、护甲、危险预警 |
| Highlighter | `#F2C14E` | 当前目标与重点提示 |

不使用紫蓝渐变、霓虹泛光、玻璃拟态。纸感来自纤维、方格、硬边错位阴影和略有偏差的手绘线，而不是全局噪点滤镜。

### 字体与版式

- 标题：`Segoe Print`、`KaiTi`，用于手写批注感。
- 正文与 HUD：`Trebuchet MS`、`Microsoft YaHei`，保证小字号可读。
- 开始页采用左右分栏：左侧是大标题与一句主张，右侧是本局任务和核心操作；窄屏改为单列。
- 游戏 HUD 只保留准星、生命、墨量、弹药、目标、倒计时和情境提示。

```text
┌──────────────────── 工作页 / 04:00 ────────────────────┐
│ 锚点 0/3                                  声音开关     │
│                                                        │
│                       准星                              │
│             情境提示 / 画线预览 / 交互进度               │
│                                                        │
│ 生命 100       墨量 100              线规笔 18 / ∞      │
└────────────────────────────────────────────────────────┘
```

### 材质与光照

- 纸张：程序生成纤维与方格纹理，粗糙度高、金属度为 0。
- 实体：哑光纸块配石墨轮廓；玩家创造物为青绿线框与纸面。
- 敌人：折纸结构配校订红外壳，擦除后外壳消失，状态立即可见。
- 光照：暖方向光产生接触阴影，低强度天空补光保留暗部；无 Bloom。
- 相机：68° FOV，克制的移动摆动与开火后坐，减少晕动。

### 声音

- 默认静音，用户主动开启后才播放。
- 使用短促合成音区分射击、命中、擦除、受伤、锚点完成和胜负。
- 无背景音乐，不自动播放；触屏设备默认关闭声音。

## 11. Demo 技术范围

- 单文件 HTML，原生 JavaScript + Three.js，无构建步骤、无后端、无账号。
- 桌面：支持指针锁定；锁定不可用时自动进入兼容模式，直接移动鼠标瞄准、左键射击，不再反复暂停。
- 触屏：左侧移动、右侧滑动瞄准，动作按钮提供射击、画线、擦除、交互、换弹、跳跃与暂停。
- 自适应像素比，标签页进入后台时暂停。
- WebGL 或 3D 库加载失败时保留明确错误提示，不伪装成可玩。

### 首版明确不做

多人联机、账号与云存档、复杂养成、武器拾取、任意形变折纸、完整寻路、手柄支持、背景音乐。

## 12. 需求到行动核对

- [x] 原创核心机制：画线、擦除；折纸作为后续规格。
- [x] 完整方案与可玩网页 Demo 同时交付。
- [x] 首版具有开始、战斗、胜利、失败、暂停、重开闭环。
- [x] 通过实际浏览器验证正常入口与核心路径。
- [x] 验证重开后状态恢复，以及控制台无新增错误。

## 13. 验收重点

1. 玩家能从开始页进入游戏，并理解“三处锚点后撤离”。
2. 两次 Q 能生成与预览一致的实体掩体，墨量正确扣除。
3. E 能消除范围内容敌人的护甲，外壳视觉同步消失。
4. 掩体能阻挡敌弹，敌人能破坏掩体，不会永久卡住。
5. 锚点必须按住 F 才能完成，松开或离开会中断。
6. 三处锚点完成后出口才可用；胜利、超时、阵亡都有结算。
7. 重开后所有状态复位，暂停时战斗与倒计时不推进。

## 14. 验证记录

验证日期：2026-11-13。核心逻辑使用临时诊断接口做确定性逐帧驱动，输入仍走游戏的 Q / E / F / Esc 与更新函数；正式 HTML 已移除全部诊断接口，并重新完成文件直达与触屏模式回归。

| 项目 | 实际结果 |
|---|---|
| 文件入口 | 本地 HTTP 与 `file://` 直接打开均能加载开始页和 3D 场景 |
| 非法画线 | 超长线条提示“最多 6 米”，不生成掩体、不扣墨 |
| 合法画线 | 生成 120 耐久实体掩体，墨量按长度扣除 |
| 掩体受击 | 敌人蓄力攻击后，掩体耐久从 120 降为 102 |
| 擦除 | 范围内首名敌人护甲从 24 降为 0，墨量立即显示 65 |
| 射击 | 擦除后两发消灭目标，敌人数 4→3，弹药 18→16 |
| 换弹 | 1.25 秒后弹药恢复至 18 |
| 胜利 | 三处锚点依次变为 1 / 2 / 3，出口解锁，交互后进入胜利结算 |
| 失败 | 生命值耗尽与倒计时结束均能进入失败结算 |
| 暂停 | 暂停后继续调用更新，倒计时保持不变 |
| 重开 | 生命 100、墨量 100、弹药 18、敌人 4、锚点 0、掩体 0、统计清零 |
| 桌面兼容 | 无 pointer lock 时自动降级，不进入暂停循环；Q / E 正常响应，左键射击后弹药 18→17 |
| 触屏界面 | 墨量反馈、画线提示、跳跃和暂停按钮可用，窄屏武器小字正确隐藏 |
| 静态检查 | JavaScript 语法通过，50 个元素 ID 无重复，无占位符、无诊断代码 |
| 控制台 | 无运行错误；Three.js 0.160.0 非模块构建存在一条官方弃用警告 |

### 尚未覆盖的验证

- 自动化环境不支持成功取得 pointer lock，因此桌面鼠标持续瞄准手感仍建议人工试玩确认。
- 触屏验证使用模拟触屏模式，不等同于真实手机性能与手感验收。
- 当前只验证首关规则闭环，没有进行长期数值平衡、多人联机或后续折纸机制测试。
