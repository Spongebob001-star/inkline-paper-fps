# D6 Boss 接口契约

> 适用分支：`d6-boss-nailong`。契约外的字段/行为视为私有，可改；契约内改动必须同步测试与本文。
> 单位：米、秒、弧度；伤害为整数。

## 1. 模块边界

```
flow.mjs ──createBoss──▶ boss.mjs ◀──stepBoss── sim.mjs
combat.mjs ──damageBoss──▶   │
                             ├──▶ enemies.mjs（createEnemy，召唤）
                             └──▶ combat.mjs（fireProjectile / damageWall / damagePlayer）
client/render.mjs ◀──snapshot.boss── sim.snapshot
```

`shared/boss.mjs` 不依赖 DOM/THREE，可无头运行。

## 2. 导出 API

| 导出 | 签名 | 语义 |
|---|---|---|
| `createBoss` | `(match) => boss` | 在 `match.boss` 创建 Boss（hp=`scaling[n].bossHp`，位置 `(0,5.5)`，`attackCd=2.5`，`nextAttack=0`，`state='idle'`），推 `bossSpawn{hp}`。重复调用会覆盖旧 Boss。 |
| `damageBoss` | `(match, n, attackerId=null) => dealt` | 唯一伤害入口。非狂暴 `dealt=ceil(n*0.35)`，狂暴 `dealt=n`；扣血至 0、记仇恨、触发 `rage`/`bossDown`。Boss 不存在或已死返回 0。 |
| `hateTarget` | `(match, boss) => player\|null` | 最近 `hateWindow` 秒伤害总和最高者；无伤害记录时回退最近存活玩家；无存活玩家返回 null。 |
| `farthestTarget` | `(match, boss) => player\|null` | 距离最远的存活玩家。 |
| `stepBoss` | `(match, dt) => void` | 推进状态机；Boss 不存在/已死/无存活玩家时直接返回。 |

## 3. Boss 对象字段（权威）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | number | `match.nextId++` |
| `x,z` | number | 平面坐标（y 恒 0） |
| `hp,maxHp` | number | 当前/上限；`scaling[n].bossHp` |
| `raged` | bool | ≤50% 触发一次；狂暴=去盾 |
| `attackCd` | number | 距下一次出招秒数 |
| `nextAttack` | number | 循环索引 `%3` → fan/summon/charge |
| `state` | `'idle'\|'fan'\|'summon'\|'charge'\|'charging'` | 蓄力状态与冲刺状态分离 |
| `telegraph` | number | 当前状态蓄力累计秒 |
| `dirX,dirZ` | number | 冲撞锁定方向（charging 时） |
| `chargeT` | number | 冲撞已持续秒 |
| `hitDone` | bool | 本次冲撞是否已结算命中/碎墙 |
| `targetId` | number\|null | 当前意图目标 |
| `faceYaw` | number | 朝向（`atan2(dx,dz)`） |
| `aimX,aimZ` | number | 冲撞预警线终点（蓄力期持续更新） |
| `dead` | bool | 死亡标记；`stepBoss` 跳过，快照置 `boss:null` |

| 键 | 值 | 键 | 值 |
|---|---|---|---|

| `boss.shieldMul` | 0.35 | `boss.hateWindow` | 5 |
| `boss.speed` | 1.8 | `boss.attackInterval` | 1.7 |
| `boss.fanTelegraph` | 0.6 | `boss.fanSpread` | 22° |
| `boss.fanSpeed` | 8 | `boss.fanDamage` | 8 |
| `boss.summonTelegraph` | 0.8 | `boss.summonCount/Big` | 3 / 4 |
| `boss.chargeTelegraph` | 0.7 | `boss.chargeSpeed` | 14 |
| `boss.chargeTime` | 1.1 | `boss.chargeDamage` | 18 |
| `boss.chargeWallDamage` | 45 | `boss.rage.*` | at .5 / interval 1.15 / speed 2.4 / fanSpeed 9.5 / fanBonus 0 |

## 5. Match / Sim 契约

| 位置 | 契约 |
|---|---|
| `match.boss` | 初始 `null`；三锚点后由 flow 创建；快照中仅在存活时输出 |
| `player.hate` | `Array<{t:number,n:number}>`；`t=match.elapsed`，`n=dealt`；仅由 `damageBoss(...,attackerId)` 写入；`hateTarget` 读取时剪枝 |
| `stepMatch` 顺序 | `stepEnemies → stepBoss → stepProjectiles → stepWalls → stepFolds → stepPickups → stepFlow` |
| `snapshot.boss` | `{hp,state,raged,x,z,t,fy,ax,az}`（坐标 2 位、t 2 位、fy 3 位小数）；死亡/不存在为 `null` |
| 随机源 | 只允许 `match.rand()`（mulberry32 种子流） |

## 6. 事件契约

| 事件 | data | 触发点 |
|---|---|---|
| `bossSpawn` | `{hp}` | `createBoss` |
| `rage` | `{}` | 首次降到 ≤50%（damageBoss 或 stepBoss 同步），每局一次 |
| `bossAttack` | `{attack:'fan',count}` / `{attack:'summon',count}` / `{attack:'charge',dirX,dirZ}` | 招式结算时刻 |
| `bossDown` | `{}` | hp 归零；同帧置 `exitUnlocked=true` |
| `hit` | `{id, point, boss:true}` | 玩家子弹命中 Boss |

## 7. 战斗/命中契约

- Boss hitbox：竖直圆柱 `x,z`、`r=CONFIG.boss.radius(1.0)`、`y∈[0,2.2]`（`applyShot` 内硬编码 2.2）。
- 玩家子弹命中 Boss → `damageBoss(match, CONFIG.player.gun.damage, shooterId)`；不区分部位。
- 冲撞伤害走 `damagePlayer(match, p, 18)`；撞墙走 `damageWall(match, w, 45)`；同一次冲撞只结算一次（`hitDone`）。
- 召唤走 `createEnemy(match,'crane',x,z,{spawnAnim:true})`，首攻 `attackCd=1.5`，受同屏 `cap` 截断。

## 8. 客户端渲染契约（`client/render.mjs`）

- 唯一数据源：`snapshot.boss`。`null` → 移除视图；非空 → 按需创建。
- 视图字段（`makeBossView` 返回）：`{g, body, bar, aura, aim, mat, cv, ctx, tex, model, lastHp, lastRaged, flash, auraT}`。
- 位置：`g.position=(b.x,0,b.z)`；朝向：`g.rotation.y=b.fy`。
- 预警线：`aim.visible = b.state==='charge'`；端点 `(b.x,1.5,b.z)→(b.ax,1.25,b.az)`。
- 狂暴：`aura.material.opacity = 0.3+0.16*sin(auraT*5)`；模型 `emissive=0x330000`（受击闪白优先）。
- 血条：`scaling[players.length].bossHp` 为分母；`raged` 时画黄顶条。
- 清理：`bossDown` 与 `reset()` 必须调用 `removeBossView()`，dispose geometry/material/texture；`aim` 为 scene 级对象，单独移除。
- 模型加载：`fetch('/src/models/bs.json')`；失败静默回退胶囊 `lam(C.yellow)`，Boss 逻辑不受影响。

## 10. 模型资产格式（`bs.json`）

| 键 | 类型 | 约定 |
|---|---|---|
| `name` | string | `"bs"` |
| `sm` | 0/1 | 1=平滑着色（Boss），0=平直 |
| `pos` | number[] | 顶点 xyz 连排，**毫米整数**，运行时 ÷1000 |
| `col` | string[] | **每顶点**一个 `"RRGGBB"`，长度 = `pos.length/3` |
| `idx` | number[] | 三角形索引（每 3 个一面），绕序已按导出管线修正 |

## 11. 单测契约（`tests/boss.test.mjs`）

必须覆盖：护盾换算；狂暴一次触发+去盾；扇形七发/22°/8 伤/速度 8；hate 5s 窗口与过期回退；冲撞最远目标；冲撞 18 单次；碎墙 45；召唤 3 与 4+cap；狂暴速度/间隔/弹速；朝向；死亡解锁；300 步同种子确定性。`tests/model.test.mjs` 额外 3 例锁模型格式/上限/朝向。改动内核或资产后 **190 例全绿**且本文件 12 例不降。
