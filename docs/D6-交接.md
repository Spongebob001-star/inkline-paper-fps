## 2. 已完成（A 侧）

### 2.1 内核 `shared/boss.mjs`
- 护盾：非狂暴期实伤 `ceil(伤×0.35)`；狂暴触发一次（≤50%），**同时解除护盾**，此后全额伤害。
- 移动/出手：移速 1.8（狂暴 2.4）；出手间隔 1.7（狂暴 1.15）；面部朝目标 `atan2(dx,dz)`。
- 三招循环 `fan → summon → charge`：
  - 扇形：蓄力 0.6s；发数按人数 7/8/9/10；散布 22°；弹速 8（狂暴 9.5）；8 伤；目标=近 5s 伤害最高者（无记录回退最近）。
  - 召唤：蓄力 0.8s；3 只（n≥3 为 4），受 `scaling[n].cap` 截断；3m 随机角落点（`match.rand` 种子化）；新敌首攻 1.5s。
  - 冲撞：蓄力 0.7s，锁定最远玩家并持续更新预警线；14m/s×1.1s；18 伤（单次）；撞玩家墙 45（<1.4m 即碎并提前结束）。
- 死亡：`bossDown` 事件 + `exitUnlocked=true`（仅一次）。

## 5. 常见坑

- 玩家贴着 Boss 表面（中心距 ≈ r=1.0）开枪时，射线起点在圆柱边界上，`t=0` 被拒 → 判定 miss。这是测试摆位问题，不是命中 bug；实战碰撞会把玩家推开。验收时站 3m 外。
- `renderer.reset()` 不重建 match；重开一局用 `restart()`。
- 页面可见时两次工具调用之间会实时推进，脚本验收前先 `pause(true)`。
- Boss 死亡不会自动切 `phase`；出口在 `exitUnlocked` 后可撤离，HUD 目标文案随 phase 变化。
